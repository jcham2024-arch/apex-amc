## Columns

| Column | Type | Req | Meaning |
|---|---|---|---|
| `slug` | string | yes | Cartridge identity, lowercase ASCII with hyphens, e.g. "308-winchester". This is the primary key and the join target for the pressure tables, so a slug change orphans every pressure figure that referenced it. |
| `name` | string | yes | Full designation as published, e.g. ".308 Winchester". |
| `short_name` | string | no | Abbreviated form used in dense UI, e.g. "308 Win". Falls back to `name`. |
| `family` | string (3 values) | yes | Also the filename. family is NOT NULL in SQLite and a wrong guess files a pistol cartridge on a rifle page, so it is constrained rather than inferred. |
| `parent_case` | string | no | Case this cartridge is loaded on. EMPTY ON ALL 229 ROWS - not yet transcribed, and deliberately left empty rather than guessed. |
| `bullet_dia_in` | number | no | Nominal bullet diameter, inches. EMPTY ON ALL ROWS. |
| `case_length_max_in` | number | no | CIP/SAAMI maximum case length, inches. EMPTY ON ALL ROWS. |
| `max_col_in` | number | no | Overall cartridge length limit, inches. EMPTY ON ALL ROWS. |
| `saami_max_psi` | integer | no | SAAMI maximum pressure, psi. The one dimension-like column that IS populated - all 229 rows carry a figure from the kwk.us compilation, with ksi rounded up to the nearest 1000 psi. |
| `saami_max_cup` | number | no | Maximum pressure in cup. Blank throughout. |
| `cip_max_bar` | number | no | CIP maximum pressure, bar. EMPTY ON ALL ROWS - CIP data is an open gap. |
| `rim_dia_in` | number | no | Rim diameter, inches. EMPTY ON ALL ROWS. |
| `head_dia_in` | number | no | Case head diameter, inches. EMPTY ON ALL ROWS. |
| `capacity_gr_h2o` | number | no | Case capacity in grains of water. EMPTY ON ALL ROWS. |
| `primer_type` | string | no | Smallest primer the case accepts, e.g. "small". EMPTY ON ALL ROWS. |
| `typical_twist_in` | number | no | Typical rifling twist rate, in per inch. EMPTY ON ALL ROWS. |
| `is_reloadable` | boolean | no | Whether the case is reloadable. The loader defaults to true when blank. |
| `notes` | string | no | Free prose. May contain commas, so it must stay quoted in the CSV. |
| `source_name` | string | no | Which publisher the row was read from. All 229 rows are "kwk.us Cartridge Pressure Standards" - one source for the whole dataset, which is why these are compilation figures rather than primary data. |
| `source_url` | string | no | Canonical URL for the figure. |
| `source_note` | string | no | How the value was derived, e.g. that ksi was rounded up. |
