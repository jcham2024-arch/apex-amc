# Retrospective and training material

Output directory for task **R3** in `.cline/tasks/ledger.json`.

Expected deliverables:

- `01-defect-taxonomy.md` - root causes, not symptoms
- `02-vacuous-gate-pattern.md` - how to tell a check that cannot fail from one that can
- `03-undocumented-risks.md` - every finding labelled PROVEN, RISK or PREFERENCE
- `04-new-agent-curriculum.md` - ordered, checkable onboarding

Findings must cite a file path and line number, or a commit hash. An unevidenced
claim that something is fragile is not a finding.

This directory exists so git records it; see the note in
`docs/research-methods/README.md` for why that matters to `tasks:check`.
