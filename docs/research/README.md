## Rules for this directory

- A note here is **evidence gathered**, not a number the app uses. Anything the
  solver depends on belongs in `data/reference/` with stated conditions and
  uncertainty, per that directory's README.
- Cite the Wayback snapshot URL rather than the publisher's bare URL. Bare URLs
  in this material have rotted; the crawl log in
  `C:\Cline\resources\references\applied-ballistics\arch_dl.log` records what
  actually resolved.
- Do not copy publisher documents into the repository. See `REFERENCE-INDEX.md`.
- Where a source disagrees with another, record both. Do not average.
